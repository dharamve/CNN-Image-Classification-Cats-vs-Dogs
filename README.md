# 🐱🐶 Cats vs Dogs Image Classification using CNN

## 📌 Project Overview

This project implements a **Convolutional Neural Network (CNN)** to classify images into two categories:

* 🐱 Cat
* 🐶 Dog

The model is built using **TensorFlow and Keras** and trained on a labeled image dataset.

The objective of this project is to understand the fundamentals of **Computer Vision and Deep Learning**, including image preprocessing, CNN architecture, model training, evaluation, and prediction.

---

## 🎯 Project Objectives

The main objectives of this project are:

* Load and preprocess image data
* Resize images to a consistent size
* Normalize pixel values
* Build a CNN model
* Train the model on labeled images
* Validate model performance
* Visualize training accuracy and loss
* Evaluate the trained model
* Save the trained CNN model
* Predict whether a new image is a cat or dog
